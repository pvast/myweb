Forecast combination

Exponential Smoothing (ETS) and The seasonal-trend decomposition with Loess forecasting (STLF) is a method for decomposing time series (link https://laurentlsantos.github.io/forecasting/seasonal-and-trend-decomposition-with-loess-forecasting-model-stlf.html)

train <- df |> filter(year(Qtr) <= 2019)
STLF <- decomposition_model(
  STL(log(GDP) ~ season(window = Inf)),
  ETS(season_adjust ~ season("N"))
)
GDP_models <- train |>
  model(
    ets = ETS(GDP),
    stlf = STLF,
    arima = ARIMA(GDP)
  ) |>
  mutate(combination = (ets + stlf + arima) / 3)
GDP_fc <- GDP_models |> forecast(h = "6 years")


GDP_fc |> autoplot(df|> filter(year(Qtr) > 1993), level = NULL) +  labs(y = "Millions",  title = "GDPcvm")

Forecast combination

distributions The GDP_fc object contains forecast distributions, from which any prediction interval can usually be computed. Let’s look at the intervals for the first period.

GDP_fc|> filter(Qtr == min(Qtr))

if we work with simulated sample paths, it is possible to create forecast distributions for the combination forecast as well.

df_future <-GDP_models|> 
  # Generate 1000 future sample paths
  generate(h = "5 years", times = 100) |>
  # Compute forecast distributions from future sample paths
  as_tibble() |>   group_by(Qtr, .model) |>
  summarise(dist = distributional::dist_sample(list(.sim)) )|>  ungroup() |>
  # Create fable object
  as_fable(index = Qtr, key = .model, distribution = dist, response = "GDP")
## `summarise()` has grouped output by 'Qtr'. You can override using the `.groups`
## argument.
## Warning: The dimnames of the fable's distribution are missing and have been set
## to match the response variables.
# Forecast distributions for h=1
df_future |> filter(Qtr == min(Qtr))

four models, including the combination, are stored as empirical distributions, and we can plot prediction intervals for the combination forecast

df_future |> filter(.model == "combination") |>
  autoplot(df |> filter(year(Qtr) > 1993)) +
  labs(y = "Millions", title = "GDPq cvm")
